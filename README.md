README
======

This folder contains the MATLAB code used to implement the ontogenetic growth model and generate the main figures presented in the manuscript.

Model
-----

body_mass_increase.m

This function implements the ontogenetic growth model described by Equations (1)–(10) in the main text. It calculates consumer growth and changes in body stoichiometry based on energy and elemental constraints.

Figure 2
--------

main_Figure_2_plot.m

This script generates Figure 2 in the main text, showing consumer growth trajectories and associated changes in energy and elemental allocation during ontogeny.

Figure 3
--------

main_Figure_3_run.m

This script runs simulations across combinations of food ingestion rate and food nutrient-to-carbon ratio. It calculates consumer body mass and body stoichiometry when growth ceases under each parameter combination.

main_Figure_3_plot.m

This script plots the simulation results generated by main_Figure_3_run.m and produces Figure 3 in the main text.

Figure 4
--------

The folder "main_Figure_4 run & plot" contains the scripts used to generate Figure 4.

main_Figure_4_1.m
main_Figure_4_2.m
main_Figure_4_3.m

These scripts simulate changes in consumer body stoichiometry until growth ceases under the different parameter combinations represented in the three columns of Figure 4.

main_Figure_4_1_plot.m
main_Figure_4_2_plot.m
main_Figure_4_3_plot.m

These scripts plot the corresponding simulation results and together generate Figure 4 in the main text.

Software
--------

All simulations and figures were produced using MATLAB.
